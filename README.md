## Hi, I'm Hassan

I'm a software developer at Full Sail University. I've been building for the web for over a decade, mostly on the frontend, and lately I've been going deeper on the backend with Java and Spring Boot.

### What I'm working on
- **[Coffee Tracker](https://github.com/hassanhibbert/coffee-tracker)**: a log for dialing in the cappuccinos I make at home. It has a Spring Boot API and a React/TypeScript client, with client types generated from the API’s OpenAPI spec.
- **[Circuit Trainer](https://github.com/hassanhibbert/circuit-trainer)**: a workout app I built for my own training. It has a Spring Boot and PostgreSQL API with JWT auth, offline sync, and tests that run against a real Postgres database, plus a React client.
- **[hassanhibbert.com](https://www.hassanhibbert.com)** ([source](https://github.com/hassanhibbert/portfolio)): my portfolio. It's plain HTML, CSS and a little JavaScript, built with Vite.
- **Plantbox** (in progress): an automatic plant-watering system on ESP8266 hardware. I'm replacing its Blynk cloud setup with my own Spring Boot backend over MQTT.
